# code-diff — правила, которые нельзя «переинтерпретировать»

## Контракт ленты ( Ribbon Contract )

Лента — ОДНА НЕРАЗРЫВНАЯ залитая полоса. Правила ниже закреплены
исполняемыми тестами `tests/model/ribbon-contract.test.ts` и
`tests/view/ribbon-contract.test.tsx`. Тесты — источник истины; журнал и
комментарии вторичны.

1. Каждый измеренный конец ленты несёт полосу (band) высотой строки над
   СВОИМИ строками цепочки. Строки вне цепочки НИКОГДА не заливаются.
2. Соседние концы соединены коннекторами (N концов → N−1 коннекторов),
   каждый путь замкнут (`Z`), залит, без stroke.
3. Талия: переполненный коридор сдвигает только плоскую середину; концы и
   полосы НЕ двигаются; плато не уходит ниже нижнего края колонок.
4. Подпись едет на плато своей ленты (внутри corridor box, сдвигается с ней).
5. Один тон: полосы и дорога ленты красятся ОДНИМ цветом темы; hot-цепочка
   целиком — одним hot-оттенком (полосы + дорога), без стекающейся альфы.
6. Group-hint — полоса высотой строки (та же форма, что лента), не проволока.
7. Односторонний член — stub высотой строки, не огрызок.
8. Hover зажигает ТОЛЬКО свою цепочку; строка не несёт собственной заливки.

## Запрет на слом

- Жалоба пользователя на заливку/подсветку относится к заливке строк ВНЕ
  цепочки (блочный wash). Она НЕ отменяет правила 1–8. Удалять полосы лент,
  сужать hint до проволоки или stub до огрызка ЗАПРЕЩЕНО.
- Любое изменение ribbon/ обязано оставлять `pnpm test` и `npx eslint .`
  зелёными. Красный контракт = коммит запрещён.
- Если претензия кажется противоречащей контракту — сначала спросить
  пользователя, что именно на экране не так; не «чинить» удалением правил.
- Сборка при WIP пользователя: `git worktree add --detach /tmp/cd-rNN HEAD`,
  node_modules симлинком; dist/demo синхронизировать обратно (gitignored).
  Чужой WIP (surface/, geometry/, interface/, columns/Items.tsx) не коммитить.
